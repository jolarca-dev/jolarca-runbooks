# On-Call

How Jolarca responds to incidents. Read these in order when joining the rotation:

1. [`severity-matrix.md`](severity-matrix.md) — how to classify what's happening.
2. [`escalation-policy.md`](escalation-policy.md) — when and how to pull in more help.
3. [`incident-response.md`](incident-response.md) — the step-by-step procedure from page to close.
4. [`rotation.md`](rotation.md) — how the on-call rotation works.
5. [`handover.md`](handover.md) — what to pass to the next shift.
